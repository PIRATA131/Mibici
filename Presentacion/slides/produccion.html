La cadena completa. Databricks hace el trabajo de datos y entrena el modelo. El modelo sale como un archivo de 1.9 megabytes que viaja en el repositorio. El API lo sirve con FastAPI dentro de un contenedor Docker que Render construye y despliega en cada push. Y el mapa consume ese endpoint por HTTP: la página nunca carga el modelo, le pregunta al servicio. Si el artefacto no estuviera, el API responde con la línea base y lo declara en su endpoint de salud, para no mentir sobre qué está respondiendo. AQUÍ VA LA DEMOSTRACIÓN EN VIVO: abrir el mapa, mover la hora, hacer clic en GDL-127, y después enseñar /docs. Recordatorio: abrir la página cinco minutos antes de exponer, porque el plan gratuito duerme el servicio.
